C01 A arquitetura em quatro zooms (C4)

Quatro níveis, do mais longe ao mais perto. A regra é simples: cada nível responde a uma pergunta diferente, e misturar dois numa figura só é como a maioria dos diagramas de arquitetura vira parede de caixinha.

1 Contexto — o sistema no mundo

Quem usa, e com o que ele conversa.

Diagrama, em texto — para entrar no semáforo como qualquer outro trecho:

flowchart LR
  P([a pessoa]) --> S[o seu sistema]
  S --> E1[sistema externo]
  S --> E2[outro externo]

Este nível é para quem não vai escrever código. Se um diretor não entende, está errado.

2 Contêineres — as partes que rodam

Cada coisa que sobe sozinha.

Diagrama, em texto — para entrar no semáforo como qualquer outro trecho:

flowchart TD
  W[navegador] --> A[API]
  A --> B[(banco)]
  A --> F[fila]

Uma caixa por processo: aplicação, API, banco, fila, job. Diga em que cada uma é escrita e como as outras falam com ela.

3 Componentes e código

Só onde vale a pena.

Desenhe o terceiro nível apenas para as partes complicadas. O quarto — o código — quase nunca vale: ele envelhece em dias, e o código já está lá para ser lido.
